🖥️ Windows 태블릿/키오스크 어플 설정 및 업데이트 매뉴얼

전체화면 단독 실행 방식별 최초 구축 가이드 & 비상 탈출/실제 exe 위치 교체 절차

Method 1

윈도우 쉘(Shell) 교체 방식 (레지스트리 활용)

부팅 시 윈도우 바탕화면 프로그램(explorer.exe) 대신, C:\ 드라이브에 설치된 C# 어플(.exe)을 메인 쉘로 자동 실행시켜 바탕화면을 완벽히 제거하는 가장 추천하는 키오스크 구축 방식입니다.

🛠️ 최초 설정 방법 (최초 단독 실행 등록)

  1. Win + R ➔ regedit 입력 후 엔터 (레지스트리 편집기 실행)
  2. 아래 경로로 이동:
    HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon
  3. 오른쪽 목록에서 Shell 항목을 더블 클릭합니다.
  4. 기존 값인 explorer.exe를 삭제하고, 실제 C# 어플의 **절대 경로**를 입력합니다.
    C:\MyApp\MyApp.exe
  5. 태블릿을 재부팅하면 윈도우 바탕화면 없이 내가 만든 C# Form 어플만 단독 실행됩니다.

🔄 최신 C# 빌드(exe) 파일 교체 상세 절차

  1. 어플 실행 상태에서 Ctrl + Shift + Esc를 눌러 **작업 관리자**를 엽니다.
  2. C# 어플을 클릭하고 **[작업 끝내기]** ➔ 바탕화면이 제거된 상태이므로 화면이 검은색으로 변합니다.
  3. 작업 관리자 상단 **[새 작업 실행]** 클릭 ➔ explorer 입력 후 엔터 ➔ **바탕화면 강제 복구!**
  4. 실제 어플 폴더 위치 찾기:
    ProgramData/.../スタートメニュー 등은 바로가기 폴더입니다. 바로가기 아이콘 우클릭 ➔ [속성(プロパティ)] ➔ [파일 위치 열기(ファイルの場所を開く)]를 눌러 진짜 C:\ 프로그램 폴더로 이동합니다.
  5. 준비해온 최신 C# 빌드 파일(Release 폴더 안의 exe 및 dll 전체)을 진짜 폴더에 **복사 및 덮어쓰기(ファイルを置き換える)** 합니다.
  6. 태블릿 재부팅 ➔ 최신 버전 어플로 단독 자동 실행 검증 완료!

💡 일본어 OS(Windows) 현장 조치 팁

  • 파일 위치 열기: 마우스 우클릭 ➔ Properties(プロパティ) ➔ Open File Location(ファイルの場所を開く)
  • 덮어쓰기 창: Replace the files in the destination(ファイルを置き換える) 클릭
Method 2

Windows 공식 키오스크 모드 (Assigned Access)

Windows 10/11에 기본 제공되는 보안 키오스크 기능입니다. 전용 계정을 만들어 특정 앱(UWP 또는 패키징된 Win32 앱) 하나만 사용하도록 잠급니다.

🛠️ 최초 설정 방법 (최초 구축)

  1. 태블릿에서 Win + i (설정) ➔ **[계정]** ➔ **[가족 및 다른 사용자]** 진입
  2. **[키오스크 설정(Assigned Access)]** 클릭
  3. [시작하기] 버튼 클릭 후 키오스크 전용 **새 계정 이름** 작성
  4. 태블릿 부팅 시 단독 실행할 어플을 목록에서 선택
  5. 재부팅 시 해당 키오스크 계정으로 자동 로그인되며 어플만 고정 실행됩니다.

🔄 업데이트 및 파일 갱신 절차

  1. 키보드의 Ctrl + Alt + Delete 키를 누릅니다.
  2. 화면 우측 하단에서 **[사용자 전환]** 또는 **[로그아웃]** 선택
  3. 관리자 계정(General Admin Account)으로 다시 로그인합니다.
  4. 관리자 바탕화면에서 C# 어플 폴더로 이동하여 최신 빌드 파일 덮어쓰기
  5. 완료 후 다시 키오스크 계정으로 로그아웃/재부팅 수행
Method 3

시작 프로그램 등록 + C# 전체화면/TopMost 설정

바탕화면은 정상 로딩되지만, 부팅되자마자 어플이 켜지면서 테두리 없이 화면 전체를 덮고 항상 위(TopMost)에 오도록 만드는 코드 중심 방식입니다.

🛠️ 최초 설정 방법 (C# 소스코드 & 자동실행)

1) C# Form 소스코드 설정:

// Form_Load 또는 Form 생성자 this.FormBorderStyle = FormBorderStyle.None; // 테두리 제거 this.WindowState = FormWindowState.Maximized; // 전체 화면 this.TopMost = true; // 항상 위에 표시

2) 윈도우 시작 프로그램 등록:

  1. Win + R ➔ shell:startup 입력 후 엔터
  2. 열린 폴더에 C# 어플의 **바로 가기(Shortcut) 파일**을 넣습니다.

🔄 업데이트 및 파일 갱신 절차

  1. 키보드의 Alt + F4 또는 Ctrl + Shift + Esc로 어플 종료
  2. 어플이 꺼지면 아래에 숨겨져 있던 윈도우 바탕화면이 나타남
  3. 최신 C# 빌드 파일 전체를 기존 폴더에 **덮어쓰기**
  4. 어플 재실행 또는 태블릿 재부팅으로 검증 완료
Summary

🚨 비상 탈출 & 현장 조치 마스터 키 요약

🔑 키보드가 있을 때 (마스터 단축키)

  • 1. 앱 종료 및 작업 관리자 열기:
    Ctrl + Shift + Esc
  • 2. 검은 화면에서 바탕화면 살리기:
    작업 관리자 ➔ [새 작업 실행] ➔ explorer 입력 후 엔터
  • 3. 화면 강제 전환 / 새 데스크톱:
    Win + Tab 또는 Alt + Tab

📱 키보드가 없는 터치 태블릿 전용

  • 1. 전원 버튼 팁:
    전원 버튼 짧게 눌러 화면 끔 ➔ 다시 켬 ➔ 잠금 화면 좌측/우측 하단 [접근성 아이콘] ➔ [화면 가상 키보드] 활성화
  • 2. 강제 복구(안전 모드) 진입:
    전원 버튼 10초 눌러 강제 종료 ➔ 켜질 때 다시 10초 눌러 강제 종료 (3회 반복) ➔ 파란색 복구 화면에서 [안전 모드] 부팅

💡 개발자 추천 향후 개선 사항

매번 현장에서 강제 종료 및 explorer를 실행하지 않으려면, C# 어플 우측 상단/하단 구석에 '숨겨진 비상 종료 버튼(예: 관리자 비밀번호 4자리 입력 시 프로그램 종료)' 코드를 구현해 두는 것이 유지보수에 가장 편리합니다.
