📘 전자교재 원클릭 자동 업로드 매뉴얼

교재 파일(.html 또는 .pdf)을 관리자 화면에 드래그하면, 서버 파일 저장과 DB 등록이 동시에 처리됩니다.

1. 작업 순서

  1. 관리자 사이트의 교재 등록 메뉴로 이동합니다.
  2. 교재에 해당하는 언어(한국어/일본어/중국어/영어)를 선택합니다.
  3. 준비된 교재 파일을 **드래그 앤 드롭 영역**에 던집니다.
  4. `업로드 성공` 메시지 및 DB SQL 반영 결과를 확인합니다.
🚨 [필수 준수] 파일 이름 저장 규칙 주의사항
  • HTML 파일명 형식: 반드시 카테고리 - N과.html 또는 카테고리_N과.html 규칙을 준수해야 합니다.
      예: 일상회화 - 1과.html (⭕) / test1.html (❌ 절대 금지)
  • 이유: 시스템이 파일 이름에서 카테고리와 과 번호를 파싱하여 DB 상품(Title)으로 연결합니다. 이름이 틀리면 학생 화면에서 교재를 구매해도 404 오류가 발생합니다.
  • 특수문자 금지: 파일명에 / \ : * ? " < > | 특수문자를 넣지 마세요.

💰 세모(캐시) 충전 & 무통장 입금 승인 매뉴얼

‘세모’는 PDF 다운로드 및 수업 티켓 구매 시 현금과 동일하게 차감되는 핵심 자산입니다.

1. 무통장 입금 승인 처리 절차

  1. 관리자 페이지 [입금/충전 승인 관리] 메뉴로 이동합니다.
  2. 신청자의 입금자명, 신청 금액(세모), 신청 일시를 확인합니다.
  3. 실제 은행 계좌(통장 내역)를 조회하여 해당 입금자명으로 정확한 금액이 입금되었는지 대조합니다.
  4. 입금이 100% 확인된 경우에만 [충전/입금 승인] 버튼을 클릭합니다.
⚠️ [경고] 무통장 승인 시 강력 주의사항
  • 통장 입금 내역 미확인 승인 절대 금지: 승인 버튼을 누르는 즉시 사용자 계정에 세모가 지급되며, 무료로 PDF 교재 다운로드 및 수업 예약이 가능해집니다.
  • 입금자명 대조 필수: 신청자 이름과 실제 입금 통장의 이름이 다를 수 있으므로(예: 타인 명의 입금) 금액과 입금 시간을 철저히 확인하세요.
  • 중복 승인 주의: 이미 승인 처리된 내역인지 반드시 확인 후 승인하세요. 실수로 중복 클릭 시 세모가 이중 지급될 수 있습니다.
💡 입금 미확인 시 대처: 입금자명이 다르거나 입금 확인이 되지 않은 건은 승인하지 말고, [보류/거절] 처리 후 고객센터 문의를 안내해야 합니다.
