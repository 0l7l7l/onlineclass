HTML 책을 PDF로 다운로드하는 SPA(단일 페이지 애플리케이션) 기반의 디지털 콘텐츠 판매 플랫폼 구조입니다. 전체적인 시스템 구조와 핵심 흐름을 정리하고, 개발 구현을 위한 가이드를 제공해 드릴게요.

1. 전체 시스템 주요 구조 요약
SPA 아키텍처 (클라이언트 중심)

좌측 사이드바 메뉴 + 우측 메인 콘텐츠 영역 (동적 렌더링)

다국어 카테고리 지원: 한국어 / 일본어 / 중국어

모달(Modal) 기반의 책 미리보기 및 결제 UI

결제 및 충전 시스템 (세모 포인트 + 무통장 입금)

방식 A (세모 포인트 보유 시): 구매 버튼 클릭 → 즉시 PDF 변환/다운로드

방식 B (세모 포인트 부족 시): "세모 포인트를 충전해주세요" 안내 메세지 표시

방식 C (직접 무통장 입금 구매): 구매 신청 → [입금 대기] 상태 → 관리자 승인 후 다운로드 권한 부여

콘텐츠 디스플레이 및 탐색

카테고리 클릭 시 단원/과별로 5개의 카드 세트 배치

< > (이전/다음) 버튼으로 슬라이드하며 과 선택
