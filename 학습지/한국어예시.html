文法 02

〜이에요 / 예요

1. 意味

名詞の後ろについて「〜です」という意味を表す述語語尾です。主に日常会話において、丁寧にご自身や物事を紹介するときに使われます。

2. 使い分けルール

名詞の最後の文字にパッチム（末尾の子音）があるかないかによって形が変わります。

💡 接続公式

  • パッチムあり ＋ 이에요
  • パッチムなし ＋ 예요
3. 詳しい解説
  • 일본 사람（日本人 / パッチムあり）: 最後の文字「람」に「ㅁ」パッチムがあるため、일본 사람 ＋ 이에요 ＝ 일본 사람이에요.（日本人です）になります。連音化により［일본사라'미'에요］のようにスムーズに発音されます。
  • 친구（友達 / パッチムなし）: 最後の文字「구」にパッチムがないため、친구 ＋ 예요 ＝ 친구예요.（友達です）になります。
4. 例文

저는 한국 사람이에요.

私は韓国人です。

이것은 휴대폰이에요.

これは携帯電話です。

여기는 회사예요.

ここは 会社です。

文法 03

1. 意味
1. 意味

名詞の後ろについて「〜ではありません / 〜じゃないです」という意味を表す否定形です。「〜이에요/예요（〜です）」の反対の表現になります。

2. 使い分けルール

主語につく助詞「이 / 가」を使い分けた後に、否定の「아니에요」を接続します。

💡 接続公式

  • パッチムあり ＋ 이 아니에요
  • パッチムなし ＋ 가 아니에요

  • 의사（医者 / パッチムなし）:

文法 04

〜이 / 가 있어요 / 없어요

1. 意味

名詞の後ろについて「〜が あります / います」（存在）および「〜が ありません / いません」（不在）を表す表現です。人物や動物、物、家族の有無などを話す時に使います。

2. 使い分けルール

パッチムの有無によって助詞「이 / 가」を使い分けた後に、「있어요」または「없어요」を接続します。

💡 接続公式

  • パッチムあり ＋ 이 있어요 / 없어요
  • パッチムなし ＋ 가 있어요 / 없어요
3. 詳しい解説と対比
  • 동생（弟・妹 / パッチムあり）:
    동생 ＋ 이 있어요 ＝ 동생이 있어요.（弟/妹がいます）
  • 누나（姉 / パッチムなし）:
    누나 ＋ 가 없어요 ＝ 누나가 없어요.（姉がいません）
4. 例文

저는 형이 있어요.

私には兄（男性から見た）がいます。

언니가 없어요.

姉（女性から見た）がいません。

文法 04-2

物 ＋ 이 / 가 있어요 / 없어요

1. 意味

物に助詞「이/가」をつけて「（物）があります / ありません」を表します。人の存在（います/いません）と同じ形で、ものや所有物を表すことができます。

2. 使い分けルール

物の単語（名詞）の末尾にパッチムがあるかどうかで「이」と「가」を使い分けます。

💡 接続公式（物）

  • パッチムあり ＋ 이 있어요 / 없어요
  • パッチムなし ＋ 가 있어요 / 없어요
3. 詳しい解説と対比
  • 책（本 / パッチムあり）:
    책 ＋ 이 있어요 ＝ 책이 있어요.（本があります）
  • 시계（時計 / パッチムなし）:
    시계 ＋ 가 없어요 ＝ 시계가 없어요.（時計がありません）
4. 例文

우산이 있어요.

傘があります。

지갑이 없어요.

財布がありません（持っていません）。

文法 05

場所 ＋ 에 있어요 / 없어요

1. 意味

場所を表す名詞の後ろに助詞「에（〜に）」をつけて、「（場所）にあります / います」や「（場所）にありません / いません」を表します。疑問詞「어디（どこ）」を使って場所を尋ねることもできます。

2. 接続ルール

「〜에」は、パッチムの有無に関わらず常に「에」を接続します。

💡 接続公式

  • パッチムあり/なし共通 ＋ 에 있어요 / 없어요
  • どこにありますか/いますか？ ＝ 어디에 있어요?

文法 11

日常の丁寧形「〜아요 / 어요」

1. 意味と基本概要

動詞や形容詞の原形（辞書形：〜다）から「다」を取った部分（語幹）の**最後の母音**によって、**「아요」**と**「어요」**を使い分けます。「〜します / 〜です」という日常会話で最も使われる丁寧な表現です。

💡 陽性母音（ㅏ, ㅗ）と 陰性母音（その他）のルール

  • 陽性母音（ㅏ, ㅗ） ＋ 아요
  • 陰性母音（ㅏ, ㅗ 以外） ＋ 어요
  • 하（하다の語幹） ＋ 여요 ＝ 해요（※하다は해요に変化）
2. 詳細分類と使い分け

【1】パッチムなし（母音が合体・縮約する）

  • 母音が「ㅏ, ㅗ」の場合 → 아요：
    ・ㅏ: 가다 → 가 ＋ 아요 ＝ 가요（行きます）
    ・ㅗ: 오다 → 오 ＋ 아요 ＝ 와요（来ます / ㅗ＋ㅏ＝와）
  • 母音が「ㅏ, ㅗ 以外」の場合 → 어요：
    ・ㅣ: 기다리다 → 기다리 ＋ 어요 ＝ 기다려요（待ちます / ㅣ＋ㅓ＝려）

【2】パッチムあり（そのまま接続する）

  • 母音が「ㅏ, ㅗ」の場合 → 아요：
    ・살다 → 살 ＋ 아요 ＝ 살아요 [사아요/サラヨ]（住んでいます）
  • 母音が「ㅏ, ㅗ 以外」の場合 → 어요：
    ・먹다 → 먹 ＋ 어요 ＝ 먹어요 [머거요/モゴヨ]（食べます）
