CHAPTER 02 국적 말하기
TODAY'S GOAL

저는 한국 사람이에요.

국적을 중국어로 말해 봅시다.
1 오늘의 문법
기본 문장
A + 是 + B(국적)
是 = 입니다.
我wǒ 是shì 韩国人Hángguó rén。
저는 한국 사람이에요.
我wǒ 是shì 日本人Rìběn rén。
저는 일본 사람이에요.
他tā 是shì 中国人Zhōngguó rén。
그는 중국 사람이에요.
2 문장 구조
我 나
+
是 ~이다
+
韩国人 한국인
💡 TIP
중국어에서 저는 한국사람“입니다”라고 말할 때 여기서 무엇'입니다'를표현할 때 是를 사용해요.
먼저我 + 是 + 사람 형태를 먼저 통째로 기억해 보세요!
3 오늘의 핵심 문장
我是韩国人。
Wǒ shì Hángguó rén.
저는 한국 사람이에요.
VOCABULARY + PRACTICE 단어 & 연습
1 오늘의 단어 · 국적
한국인 韩国人Hángguó rén
일본인 日本人Rìběn rén

2. 문장을 만들어 보세요 ✏️
오늘 배운 「A + 是 + B」를 사용하세요.
① 저는 일본 사람이에요.
我是日本人。
② 그는 중국 사람이에요.
他是中国人。
③ 그녀는 한국 사람이에요.
她是韩国人。
④ 빈칸에 들어갈 단어를 골라보세요.
我 ___ 韩国人。
① 吃 ② 是 ③ 喝
정답: ② 是
⑤ 단어를 올바른 순서로 배열하세요.
韩国人 / 是 / 我
我是韩国人。

CHAPTER 02 직업 말하기
TODAY'S GOAL

저는 선생님이에요.

직업을 중국어로 말해 봅시다.
1 오늘의 문법
기본 문장
A + 是 + 직업
是 = ~이다 / ~이에요

저는 선생님이에요.
他tā 是shì 学生xuésheng。
그는 학생이에요.
2 문장 구조
我 나
+
是 ~이다
+
老师 선생님
💡 초보 TIP
직업을 나타낼 때도 是를 그대로 사용해요.
我 + 是 + 직업 형태로 나의 신분을 소개해보세요!
3 오늘의 핵심 문장
我是老师。
Wǒ shì lǎoshī.
저는 선생님이에요.
VOCABULARY + PRACTICE 직업 단어 & 연습

선생님 老师lǎoshī

CHAPTER 02 가족 소개하기
TODAY'S GOAL

그는 친구예요.

가족과 주변 사람을 중국어로 소개해 봅시다.
1 오늘의 문법
기본 문장
A + 是 + 가족·호칭
是 = ~이다 / ~이에요
她tā 是shì 姐姐jiějie。
그녀는 언니예요.
他tā 是shì 朋友péngyou。
그는 친구예요.
2 문장 구조
他 그
+
是 ~이다
+
朋友 친구
💡 초보 TIP
가족이나 지인을 소개할 때도 是를 사용하여
누구 + 是 + 호칭 형태로 표현할 수 있어요!
3 오늘의 핵심 문장
他是朋友。
Tā shì péngyou.
그는 친구예요.
VOCABULARY + PRACTICE 가족 단어 & 연습
1 오늘의 단어 · 가족
언니/누나 姐姐jiějie
오빠/형 哥哥gēge
할아버지 爷爷yéye
친구 朋友péngyou
2. 문장을 만들어 보세요 ✏️
오늘 배운 가족 및 지인 표현을 완성해 보세요.
① 그녀는 언니예요.
她是姐姐。
② 유유는 오빠예요.
悠悠是哥哥。
③ 치시는할아버지예요.
七夕是爷爷。
④ 그는 친구예요.
他是朋友。
