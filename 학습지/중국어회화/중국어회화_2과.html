TODAY'S GOAL

저는 독일 사람이 아니에요.

국적이 아님을 중국어로 말해 봅시다.
1 오늘의 문법
부정 문장
A + 不是 + B(국적)
不是 = ~이/가 아니다
我wǒ 不bú是shì 德Dé国guó人rén。
저는 독일 사람이 아니에요.
他tā 不bú是shì 加Jiā拿ná大dà人rén。
그는 캐나다 사람이 아니에요.
她tā 不bú是shì 澳Ào大dà利lì亚yà人rén。
그녀는 호주 사람이 아니에요.
2 문장 구조
我 나
+
不是 ~가 아니다
+
德国人 독일인
💡 TIP
不是는 不(아니다) + 是(~이다)가 합쳐져 "~이/가 아니다"라는 부정의 뜻을 만들어요.
'不'는 뒤에 4성(是)이 오면 성조가 2성(bú)으로 변해 bú shì로 발음해요!
3 오늘의 핵심 문장
我不是德国人。
Wǒ bú shì Déguó rén.
저는 독일 사람이 아니에요.
VOCABULARY + PRACTICE 단어 & 연습
1 오늘의 단어 · 국적
독일인 德Dé国guó人rén
캐나다인 加Jiā拿ná大dà人rén
호주인 澳Ào大dà利lì亚yà人rén
2. 문장을 만들어 보세요 ✏️
오늘 배운 「A + 不是 + B」를 사용하세요.
① 저는 독일 사람이 아니에요.
我不是德国人。
② 그는 캐나다 사람이 아니에요.
他不是加拿大人。
③ 그녀는 호주 사람이 아니에요.
她不是澳大利亚人。
④ 빈칸에 알맞은 부정 표현을 골라보세요.
我 ___ 德国人。
① 是 ② 不是 ③ 不
정답: ② 不是
⑤ 단어를 올바른 순서로 배열하세요.
不是 / 我 / 加拿大人
我不是加拿大人。
