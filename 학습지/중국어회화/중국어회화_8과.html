CHAPTER 01 어느 나라 사람인가요?
TODAY'S GOAL

당신은 한국 사람인가요?

문장 끝에 吗를 붙여 물어봅시다.
1 오늘의 문법
의문문 만들기
평서문 + 吗 ?
吗 = ~입니까? / ~인가요? (질문표현)
你nǐ 是shì 韩Hán国guó人rén 吗ma？
당신은 한국 사람인가요?
你nǐ 是shì 哪nǎ国guó人rén？
당신은 어느 나라 사람인가요?
2 문장 구조
你是韩国人 당신은 한국인이다
+
吗？ ~인가요?
💡 초보 TIP
중국어는 문장 순서를 바꾸지 않고 문장 제일 끝에 吗만 붙이면 질문이 돼요!
3 오늘의 핵심 문장
你是哪国人？
Nǐ shì nǎ guó rén?
당신은 어느 나라 사람인가요?
VOCABULARY + PRACTICE 단어 & 연습
1 오늘의 단어 · 국적 & 질문
어느 哪nǎ
나라 国guó
중국인 中Zhōng国guó人rén
미국인 美Měi国guó人rén
2. 문장을 만들어 보세요 ✏️
「~吗?」를 사용해 질문으로 바꿔보세요.
① 그는 중국 사람인가요?
他是中国人吗？
② 그녀는 미국 사람인가요?
她是美国人吗？
③ 당신은 선생님인가요?
你是老师吗？
🎤 3. 혼자 말해보기
你是 ______ 吗？
韩国人 中国人 美国人 老师
CHAPTER 02 이것은 무엇인가요?
TODAY'S GOAL

이것은 책인가요?

지시대명사(这/那)와 위치 표현을 익혀 봅시다.
1 오늘의 문법
지시대명사 의문문
这 / 那 + 是 + 사물 + 吗？
这 = 이것 / 那 = 그것, 저것
这zhè 是shì 书shū 吗ma？
이것은 책인가요?
那nà 是shì 什shén么me？
저것은 무엇인가요?
2 문장 구조
这 / 那 이것 / 저것
+
是 ~이다
+
什么？ 무엇
💡 초보 TIP
가까운 곳은 这(zhè) / 这里(zhèlǐ),
멀리 있는 곳은 那(nà) / 那里(nàlǐ)를 사용해요!
3 오늘의 핵심 문장
这是什么？
Zhè shì shénme?
이것은 무엇인가요?
VOCABULARY + PRACTICE 지시대명사 & 연습
1 오늘의 단어 · 지시대명사
이것 / 여기 这zhè / 这zhè里lǐ
저것 / 저기 那nà / 那nà里lǐ
어디 哪nǎ里lǐ
무엇 什shén么me
2. 문장을 만들어 보세요 ✏️
지시대명사와 吗를 활용해 문장을 완성하세요.
① 저것은 책인가요?
那是书吗？
② 여기는 어디인가요?
这是哪里？
③ 이것은 당신의 것인가요?
这是你的吗？
🎤 3. 질문해 보기
这 / 那 是 ______ 吗？
书 手机 包
CHAPTER 03 물건 물어보기
TODAY'S GOAL

이것은 핸드폰인가요?

주변 물건의 이름을 묻고 답해 봅시다.
1 오늘의 문법
사물 확인 문장
这 + 是 + 물건 + 吗？
네, 맞아요 = 是 / 아니요 = 不是
这zhè 是shì 手shǒu机jī 吗ma？
이것은 핸드폰인가요?
是shì，这zhè是shì手shǒu机jī。
네, 이것은 핸드폰입니다.
2 문장 구조
这 이것
+
不是 ~이 아니다
+
水 물
💡 초보 TIP
부정할 때는 是 앞에 不(bù)를 붙여 不是(bú shì)라고 말해요.
3 오늘의 핵심 문장
这是手机吗？
Zhè shì shǒujī ma?
이것은 핸드폰인가요?
VOCABULARY + PRACTICE 물건 단어 & 연습
1 오늘의 단어 · 물건
책 书shū
핸드폰 手shǒu机jī
가방 包bāo
물 水shuǐ
차/티 茶chá
커피 咖kā啡fēi
2. 문장을 만들어 보세요 ✏️
물건 단어를 넣어 질의응답을 완성하세요.
① 이것은 가방인가요?
这是包吗？
② 저것은 커피인가요?
那是咖啡吗？
③ 이것은 차가 아니에요.
这不是茶。
🎤 3. 묻고 답해보기
A: 这是水吗？
B: 是，这是水。 / 不是，这是茶。
CHAPTER 04 상태 물어보기
TODAY'S GOAL

오늘 바쁜가요?

형용사 뒤에 吗를 붙여 상태를 물어봅시다.
1 오늘의 문법
형용사 의문문
주어 + 형용사 + 吗？
형용사 문장에서는 是를 쓰지 않아요!
你nǐ 忙máng 吗ma？
당신은 바쁜가요?
我wǒ 很hěn 忙máng。
저는 매우 바쁩니다.
2 문장 구조
你 당신
+
累 피곤하다
+
吗？ ~인가요?
💡 초보 TIP
형용사로 긍정 대답을 할 때는 습관적으로 앞에 很(hěn)을 붙여줘요.
3 오늘의 핵심 문장
你忙吗？
Nǐ máng ma?
당신은 바쁜가요?
VOCABULARY + PRACTICE 형용사 & 연습
1 오늘의 단어 · 형용사
바쁘다 忙máng
피곤하다 累lèi
좋다/안녕하다 好hǎo
비싸다 贵guì
맛있다 好hǎo吃chī
매우/아주 很hěn
2. 문장을 만들어 보세요 ✏️
형용사와 吗를 조합하여 질문을 만들어 보세요.
① 당신은 피곤한가요?
你累吗？
② 이것은 비싼가요?
这贵吗？
③ 중국어는 재미있나요?
中文好玩吗？
🎤 3. 상태 대답해보기
A: 你累吗？
B: 我很累。 / 我不累。
