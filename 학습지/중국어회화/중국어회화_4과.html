CHAPTER 03 소유 부정하기 (물건)
TODAY'S GOAL

이것은 스마트폰이 아니에요 / 없어요.

물건을 가지고 있지 않다고 말해 봅시다.
1 오늘의 문법
기본 문장
A + 没有 + B(물건)
没有 = 없다 / 가지고 있지 않다
这zhè 没有méiyǒu 手机shǒujī。
이것은 스마트폰이 없어요. (폰이 없어요)
我wǒ 没有méiyǒu 电脑diànnǎo。
저는 컴퓨터가 없어요.
那nà 没有méiyǒu 钥匙yàoshi。
저것은 열쇠가 없어요.
2 문장 구조
这 / 那 이것 / 저것
+
没有 없다
+
东西 물건
💡 초보 TIP
有(있다)의 부정을 만들 때는 不有가 아니라 반드시 没有를 사용해요!
'이것(这) / 그것·저것(那) / 어느 것(哪)' 지시대명사 뒤에 没有 + 물건을 붙여보세요.
3 오늘의 핵심 문장
我没有手机。
Wǒ méiyǒu shǒujī.
저는 스마트폰이 없어요.

2. 문장을 만들어 보세요 ✏️
오늘 배운 「지시/주어 + 没有 + 물건」을 사용하세요.
① 저는 지갑이 없어요.
我没有钱包。
② 이것은 책이 없어요.
这没有书。
③ 저것은 컴퓨터가 없어요.
那没有电脑。
④ 빈칸에 들어갈 알맞은 단어를 골라보세요.
我 ___ 钥匙。(나는 열쇠가 없다)
① 不 ② 没有 ③ 是
정답: ② 没有

CHAPTER 03 장소에 존재 부정하기
TODAY'S GOAL

여기에는 사람이 없어요.

장소에 사람이나 동물이 없다고 말해 봅시다.
1 오늘의 문법
기본 문장
장소(这儿/那儿) + 没有 + 사람/동물
这儿 = 여기 / 那儿 = 거기·저기
这儿zhèr 没有méiyǒu 人rén。
여기에는 사람이 없어요.
那儿nàr 没有méiyǒu 狗gǒu。
저기에는 강아지가 없어요.
这儿zhèr 没有méiyǒu 猫māo。
여기에는 고양이가 없어요.
2 문장 구조
这儿 여기
+
没有 없다
+
人 / 狗 사람 / 강아지
💡 초보 TIP
'여기(这儿)', '저기(那儿)', '어디(哪儿)'와 같은 장소 표현 뒤에 没有 + 대상을 쓰면 "이 장소에 대상이 없다"라는 뜻이 돼요!
3 오늘의 핵심 문장
这儿没有人。
Zhèr méiyǒu rén.
여기에는 사람이 없어요.
VOCABULARY + PRACTICE 장소 · 사람/동물 단어 & 연습
1 오늘의 단어 · 장소 & 생물

사람 人rén
의사 医生yīshēng
학생 学生xuésheng
강아지 狗gǒu

2. 문장을 만들어 보세요 ✏️
장소와 없음을 나타내는 표현을 연습해 보세요.
① 저기에는 의사가 없어요.
那儿没有医生。
② 여기에는 강아지가 없어요.
这儿没有狗。
③ 저기에는 고양이가 없어요.
那儿没有猫。
④ 알맞은 문장을 완성하세요.
这儿 没有 ____。(여기에는 학생이 없어요)
这儿没有学生。
