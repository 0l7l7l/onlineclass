CHAPTER 03 일상 행동 말하기
TODAY'S GOAL

저는 매일 운동해요.

시간 표현과 동사를 함께 사용하여 일상 행동을 말해 봅시다.
1 오늘의 문법
기본 문장 (현재·습관 표현)
주어 + 시간·빈도 + 동사 (+ 목적어)
현재 동작이나 평소 습관은 별도의 어미 없이 [동사]를 그대로 써서 '~해요'라고 표현해요.
我wǒ 每天měitiān 运动yùndòng。
저는 매일 운동해요.
我wǒ 经常jīngcháng 喝咖啡hē kāfēi。
저는 자주 커피를 마셔요.
他tā 今天jīntiān 工作gōngzuò。
그는 오늘 일해요.
2 문장 구조
我 나
+
每天 매일
+
运动 운동하다
💡 초보 TIP
중국어에서는 **시간 및 빈도 부사(매일, 오늘, 자주 등)**가 기본적으로 **[동사 앞]**에 위치합니다!
주어 + 시간/빈도 + 동사 순서를 꼭 기억하세요.
3 오늘의 핵심 문장
我每天运动。
Wǒ měitiān yùndòng.
저는 매일 운동해요.
VOCABULARY + PRACTICE 단어 & 연습
1 오늘의 단어 · 시간/빈도 & 행동
매일 每天měitiān
항상 总是zǒngshì
자주 经常jīngcháng
가끔 有时候yǒu shíhou
오늘 今天jīntiān
내일 明天míngtiān
운동하다 运动yùndòng
공부하다 学习xuéxí
일하다 工作gōngzuò
커피를 마시다 喝咖啡hē kāfēi
2. 문장을 만들어 보세요 ✏️
오늘 배운 「시간/빈도 + 동사」 조합을 사용하세요.
① 저는 매일 공부해요.
我每天学习。
② 그는 항상 일해요.
他总是工作。
③ 저는 가끔 커피를 마셔요.
有时候我喝咖啡。 / 我有时候喝咖啡。
④ 빈칸에 들어갈 올바른 위치를 골라보세요.
我 ( A ) 经常 ( B ) 学习 ( C )。
① A ② B ③ C
정답: ① A (주어 我 뒤, 동사 学习 앞인 A 위치에 들어갑니다)
⑤ 단어를 올바른 순서로 배열하세요.
运动 / 明天 / 我
我明天运动。
