-아서 / -어서 理由と結果を伝えましょう
  
-아서 / -어서
  
〜だから / ～ので (理由・原因)
日常会話で使ってみましょう！
  
비가 와서 집에 있어요.
  
雨が降って(降るので) 家にいます。
  
배가 고파서 밥을 먹어요.
  
お腹が空いて(空いたので) ごはんを食べます。
  
날씨가 좋아서 산책해요.
  
天気が良くて(良いので) 散歩します。
  
ここがポイント！
  
        
  • 「-아서/어서」は「〜だから／〜ので」という原因や理由を表す表現です。
    •     
  • 【前の文（原因）】＋ **[-아서/어서]** ＋【後の文（結果）】の順でつなぎます。
    •     
  • 「왜？（どうして？）」と理由を聞かれた時の返答にも大活躍します！
    •

해서
  
  
3つのパターンだけ覚えましょう！
  
        
  • 1. -아서 : 가다 ➔ 가서 (行って) / 오다 ➔ 와서 (来て) / 보다 ➔ 봐서 (見て)
    •     
  • 2. -어서 : 먹다 ➔ 먹어서 (食べて) / 읽다 ➔ 읽어서 (読んで)
    •     
  • 3. 해서 : 공부하다 ➔ 공부해서 (勉強して) / 피곤하다 ➔ 피곤해서 (疲れて)
    •

第3課 · 実践会話
理由を言ってみましょう

どうして行かないの？ / どうして行くの？

シチュエーション別表現
  
머리가 아파서 쉬어요.
  
頭が痛くて(痛いので) 休んでいます。
  
시간이 없어서 못 가요.
  
時間がなくて(ないので) 行けません。
  
한국 음식이 맛있어서 좋아해요.
  
韓国料理が美味しくて(美味しいので) 好きです。
  
    
A (友達)
     오늘 왜 안 와요?
(今日どうして来ないの？)   
  
    
B (私)
     감기에 걸려서 못 가요.
(風邪をひいて行けないんだ。)   
  
    
A (友達)
     아, 그래요? 약 먹고 쉬어요!
(あ、そうですか？薬を飲んで休んでね！)   
注意点
気をつけるポイント！

名詞 + 라서 / 이라서

  
⚠️ 名詞の後ろには「-(이)라서」
  
        
  • 名詞につける時は「-아서/어서」ではなく「-(이)라서」を使います。
    •     
  • パッチムあり ➔ 이라서 (학생이라서 = 学生なので)
    •     
  • パッチムなし ➔ 라서 (친구라서 = 友達だから / 휴일이라서 = 休日だから)
    •   
名詞接続の例文
  
오늘 일요일이라서 쉬어요.
  
今日、日曜日なので休んでいます。
  
학생이라서 돈이 없어요.
  
学生なのでお金がありません。
  
비행기라서 빠르고 편해요.
  
飛行機なので速くて快適です。
