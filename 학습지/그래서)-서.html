文法解説
-아서 / -어서: 理由・原因を表す表現
-아서 / -어서
〜だから / ～ので (理由・原因)
解説
「-아서/어서」とは？
  • 前文が原因・理由、後文が結果になる時につなぐ表現です。（日本語の「〜だから」「〜ので」に相当）
  • 日常会話で「どうして？」と聞かれた時や、理由を説明する時に一番よく使います！
変形方法 (変形ルール)
語幹の最後の母音
ㅏ, ㅗ (陽性母音)
ㅓ, ㅜ, ㅣ など (陰性母音)
하다 (〜する)
結合する形
-아서
-어서
해서
例文
비가 와서 집에 있어요.
雨が降って(降るので) 家にいます。
배가 고파서 밥을 먹어요.
お腹が空いて(空いたので) ごはんを食べます。
날씨가 좋아서 산책해요.
天気が良くて(良いので) 散歩します。

名詞
名詞 + (이)라서: 名詞の活用ルール
⚠️ 名詞の後ろは「-(이)라서」！
  • 名詞に接続する時は「-아서/어서」ではなく「-(이)라서」を使います。
  • パッチムあり ➔ -이라서 (학생 ➔ 학생이라서)
  • パッチムなし ➔ -라서 (친구 ➔ 친구라서)
名詞の変形練習表
名詞 (意味) パッチム 変形 (-(이)라서)
학생 (学生) あり (O) 학생 + 이라서 ➔
일요일 (日曜日) あり (O) 일요일 + 이라서 ➔
한국 사람 (韓国人) あり (O) 사람 + 이라서 ➔
친구 (友達) なし (X) 친구 + 라서 ➔
휴일 (休日) あり (O) 휴일 + 이라서 ➔
오늘 (今日) あり (O) 오늘 + 이라서 ➔
名詞の例文
오늘 일요일이라서 쉬어요.
今日、日曜日なので休んでいます。
학생이라서 돈이 없어요.
学生なのでお金がありません。
친구라서 도와줘요.
友達なので助けます。

名詞 + 라서 / 이라서

  
⚠️ 名詞の後ろには「-(이)라서」
  
        
  • 名詞につける時は「-아서/어서」ではなく「-(이)라서」を使います。
    •     
  • パッチムあり ➔ 이라서 (학생이라서 = 学生なので)
    •     
  • パッチムなし ➔ 라서 (친구라서 = 友達だから / 휴일이라서 = 休日だから)
    •
