意味

文法 03

이 / 가 아니에요

1. 意味

名詞の後ろについて「〜ではありません / 〜じゃないです」という意味を表す否定形です。「-이에요/예요（〜です）」の反対の表現になります。

2. 使い分けルール

主語につく助詞「이 / 가」を使い分けた後に、否定の「아니에요」を接続します。

💡 接続公式

  • パッチムあり ＋ 이 아니에요
  • パッチムなし ＋ 가 아니에요
3. 詳しい解説と対比
  • 학생（学生 / パッチムあり）:
    학생 ＋ 이 아니에요 ＝ 학생이 아니에요.（学生ではありません）
  • 의사（医者 / パッチムなし）:
    의사 ＋ 가 아니에요 ＝ 의사가 아니에요.（医者ではありません）
4. 例文

저는 일본 사람이 아니에요.

私は日本人ではありません。（韓国人です）

이것은 제 모자가 아니에요.

これは私の帽子ではありません。

文法 04

이 / 가 있어요 / 없어요

1. 意味

名詞の後ろについて「〜が あります / います」（存在）および「〜が ありません / いません」（不在）を表す表現です。人物や動物、物、家族の有無などを話す時に使います。

2. 使い分けルール

パッチムの有無によって助詞「이 / 가」を使い分けた後に、「있어요」または「없어요」を接続します。

💡 接続公式

  • パッチムあり ＋ 이 있어요 / 없어요
  • パッチムなし ＋ 가 있어요 / 없어요
3. 詳しい解説と対比
  • 동생（弟・妹 / パッチムあり）:
    동생 ＋ 이 있어요 ＝ 동생이 있어요.（弟/妹がいます）
  • 누나（姉 / パッチムなし）:
    누나 ＋ 가 없어요 ＝ 누나가 없어요.（姉がいません）
4. 例文

저는 형이 있어요.

私には兄（男性から見た）がいます。

언니가 없어요.

姉（女性から見た）がいません。

文法 08

位置

位置 ＋ 에 있어요 / 없어요

意味

位置を表す名詞（上・下・横など）の後ろに助詞「에」をつけて「〜（位置）にあります・います／〜（位置）にありません・いません」という意味を表します。具体的なモノや人の場所・位置関係を伝えるときに使います。

使い分けルール

💬 位置を表す単語と助詞「에」の接続

「名詞 ＋ 位置単語 ＋ 에 있어요/없어요」の順で組み合わせて使います。

[名詞] ＋ [位置] ＋ [助詞] ＋ [存在]
책상 위 (机の上) ＋ 에 있어요
가방 안 (カバンの中) ＋ 에 없어요
책상 위에 있어요 가방 안에 없어요
解説
  • 위（上）/ 아래（下）/ 옆（横・隣）: 位置単語の直後に「에」をつけます（例：위 ＋ 에 ➔ 위에［위에］）。

문장 연결하기

그리고

意味

2つの文章を並列につなぐ「そして」「それから」という意味の接続詞です。前の文で述べた内容に、さらに情報を付け加えるときに使います。

💡 接続公式

💬 文章をつなぐ基本ルール

前の文を一度「.（ピリオド）」で終わらせた後、次の文の 문두(文頭) に 그리고 を置きます。

[文 A] ＋ 그리고 ＋ [文 B]
저는 학생이에요. ＋ 그리고 ＋ 한국 사람이에요.
저는 학생이에요. 그리고 한국 사람이에요.
Point
  • 文章と文章をつなぐ: 「그리고」は単語と単語を直接つなぐのではなく、基本的に「文. 그리고 文.」の形で文章同士をつなぎます。
  • 日常会話でもよく使う: 「Aです。そしてBです。」のように、自分の self-introduction（Self-introduction）や状況を続けて説明するときにとても便利です。

過去動詞

💡 この課で学ぶこと (이 단원에서 배우는 것)

  • 動詞や形容詞の後ろについて「〜しました / 〜でした」という過去の事実や完了した出来事を表す丁寧な過去形です。

Grammar
文法 11

日常の丁寧形「〜아요 / 어요」

意味

動詞や形容詞の原形（辞書形：〜다）の語幹の最後の母音によって、「아요」と「어요」を使い分けます。「〜します / 〜です」という日常会話で最も使われる丁寧な表現です。

意味

「何」「何を」という意味で、事物や行動の内容をたずねるときに使う疑問代名詞です。（「무엇」の縮約形です）

💡 接続公式

💬 単独で使える！

「무슨」「어떤」のように後ろに名詞をつけず、単独で「뭐예요?（何ですか？）」「뭐 해요?（何をしますか？）」のように使います。

뭐 ＋ 이에요/예요?（何ですか？） 뭐 ＋ 動詞?（何を〜しますか？）
이것은 ＋ 뭐예요? 오늘 ＋ 뭐 해요? / 뭐 먹어요?
이것은 뭐예요? 뭐 해요? / 뭐 먹어요?
Point
  • 助詞「를/을（〜を）」の省略: 「뭐를 먹어요?（何を 먹어요?）」の「를」が省略されて、日常会話では単に「뭐 먹어요?」とよく言います。
  • 「무슨」「어떤」「뭐」の比較まとめ:
    • 뭐 해요? : 何をしますか？（단독 사용）
    • 무슨 운동을 해요? : 何の（どんな種類の）運動をしますか？
    • 어떤 사람을 좋아해요? : どんな（どのようなタイプの）人が好きですか？

무엇인지 물어보기

무슨 ＋ 명사

意味

名詞の前に置いて「何の〜」「どんな〜」と、対象の種類や内容をたずねるときに使う冠詞（관형사）です。

💡 接続公式

💬 名詞の前に置くだけ！

パッチムの有無に関係なく、たずねたい名詞の直前に「무슨」を置きます。

무슨 ＋ 名詞（何の〜 / どんな〜）
무슨 ＋ 일 (仕事・用事) / 음식 (食べ物) / 요일 (曜日)
무슨 일 / 무슨 음식을 좋아해요?
Point
  • 名詞とセットで使う: 「무슨」は単独では使えず、必ず後ろに名詞が来ます。（例: 무슨 일, 무슨 영화, 무슨 색）
  • 「뭐（何）」との違い:
    • 뭐 : 「이것은 뭐예요?（これは何ですか？）」 ➔ 単独で使う
    • 무슨 ＋ 名詞 : 「무슨 영화를 봐요?（何の映画を見ますか？）」 ➔ 名詞を修飾する

성격이나 특징 물어보기

어떤 ＋ 명사

意味

名詞の前に置いて「どんな〜」「どのような〜」と、対象の性質・状態・特徴をたずねるときに使う冠詞（관형사）です。

💡 接続公式

💬 名詞の前に置くだけ！

パッチムの有無に関係なく、たずねたい名詞の直前に「어떤」を置きます。

어떤 ＋ 名詞（どんな〜 / どのような〜）
어떤 ＋ 사람 (人) / 옷 (服) / 음식 (食べ物)
어떤 사람 / 어떤 옷을 사고 싶어요?
Point
  • 「무슨」との使い分け:
    • 무슨 ＋ 名詞 : 種類（カテゴリー）をたずねる ➔ 「무슨 운동?（何のスポーツ？ ➔ サッカー）」
    • 어떤 ＋ 名詞 : 特徴や状態、タイプをたずねる ➔ 「어떤 사람?（どんな人？ ➔ 親切な人）」
  • 回答には形容詞修飾形（-(은)ㄴ）がよく使われる: 「어떤 옷?」という質問には「예쁜 옷（可愛い服）」や「따뜻한 옷（暖かい服）」のように答えます。

방법이나 상태 물어보기

어떻게 ＋ 동사 / 형용사

意味

「どのように」「どうやって」「いかが」「どう」という意味で、方法・手段・ state（ cardboard 状態）などをたずねるときに 쓰는 疑問副詞です。

💡 接続公式

💬 動詞や形容詞の前に置くだけ！

パッチムの有無に関係なく、たずねたい動詞や形容詞の直前に「어떻게」を置きます。

어떻게 ＋ 動詞（どうやって〜しますか？） 어떻게 ＋ 형용사/되다（どうですか/どうなりますか？）
어떻게 ＋ 가요? (行きますか？) / 써요? (書きますか？) 어떻게 ＋ 생겼어요? ( 似ていますか/どんな顔ですか？)
어떻게 가요? (どうやって行きますか？) 어떻게 지내요? (どう過ごしていますか？)
Point
  • 交通手段や行き方を聞く: 「학교에 어떻게 가요?（学校へどうやって行きますか？）」➔ 電車やバスなどの「方法」をたずねます。
  • 挨拶フレーズ: 「어떻게 지내요?（いかがお過ごしですか？ / どう過ごしていますか？）」は日常の挨拶としてよく使われます。
  • 「어떤」との違い:
    • 어떤 ＋ 名詞 : 「어떤 사람?（どんな人？ ➔ 名詞を修飾）」
    • 어떻게 ＋ 動詞 : 「어떻게 해요?（どうやってしますか？ ➔ 動作や方法を修飾）」

수단이나 도구 나타내기

명사 ＋ (으)로

意味

名詞の後ろについて、交通手段・道具・言語などの「〜で」「〜によって」「〜を使って」という意味を表す助詞です。

💡 接続公式

💬 パッチムの有無（＋ㄹパッチム）による接続ルール

名詞の最後の文字にパッチムがあるかないか、または「ㄹ」パッチムかによって形が変わります。

パッチム なし ❌ / ㄹパッチム 🌟 パッチ 가あり ⭕ (ㄹ以外)
버스 (バス) / 지하철 (地下鉄)
＋
로 		펜 (ペン) / 한국어 ✕ ➔ 한국말 (韓国語)
＋
으로
버스로 / 지하철로 펜으로 / 한국말 (한국어로)
Point

配慮・授受

相手のための行動

-아/어 주다

意味

動詞につけて「〜してあげる / 〜してくれる」という意味を表します。相手のために何らかの行動をする（または相手が自分のために行動してくれる）時に使う表現です。

💡 接続公式 (かんたんルール)

💬 해요体（ヘヨ体）を活用した接続

해요体の「요」を消して「줘요」をつけるだけで簡単に作ることができます。

기본형（基本形） 해요体 ➔ 変化
가다 / 먹다 가요 / 먹어요 ＋ 줘요
가다 / 먹다 / 하다 가줘요 / 먹어줘요 / 해줘요
Point
  • 文型公式: 「A가 B한테 V-아/어 줘요（Aが Bに 〜してあげます/くれます）」の形で使います。
  • 日本語との違い: 日本語の「あげる」「くれる」「もらう」は、韓国語では基本的に -아/어 주다 ひとつで表します。
