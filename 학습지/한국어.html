意味

文法 03

이 / 가 아니에요

1. 意味
1. 意味

名詞の後ろについて「〜ではありません / 〜じゃないです」という意味を表す否定形です。「-이에요/예요（〜です）」の反対の表現になります。

2. 使い分けルール

主語につく助詞「이 / 가」を使い分けた後に、否定の「아니에요」を接続します。

💡 接続公式

  • パッチムあり ＋ 이 아니에요
  • パッチムなし ＋ 가 아니에요
3. 詳しい解説と対比
  • 학생（学生 / パッチムあり）:
    학생 ＋ 이 아니에요 ＝ 학생이 아니에요.（学生ではありません）
  • 의사（医者 / パッチムなし）:
    의사 ＋ 가 아니에요 ＝ 의사가 아니에요.（医者ではありません）
4. 例文

저는 일본 사람이 아니에요.

私は日本人ではありません。（韓国人です）

이것은 제 모자가 아니에요.

これは私の帽子ではありません。

文法 04

이 / 가 있어요 / 없어요

1. 意味

名詞の後ろについて「〜が あります / います」（存在）および「〜が ありません / いません」（不在）を表す表現です。人物や動物、物、家族の有無などを話す時に使います。

2. 使い分けルール

パッチムの有無によって助詞「이 / 가」を使い分けた後に、「있어요」または「없어요」を接続します。

💡 接続公式

  • パッチムあり ＋ 이 있어요 / 없어요
  • パッチムなし ＋ 가 있어요 / 없어요
3. 詳しい解説と対比
  • 동생（弟・妹 / パッチムあり）:
    동생 ＋ 이 있어요 ＝ 동생이 있어요.（弟/妹がいます）
  • 누나（姉 / パッチムなし）:
    누나 ＋ 가 없어요 ＝ 누나가 없어요.（姉がいません）
4. 例文

저는 형이 있어요.

私には兄（男性から見た）がいます。

언니가 없어요.

姉（女性から見た）がいません。

意味

文法 11

日常の丁寧形「〜아요 / 어요」

意味

動詞や形容詞の原形（辞書形：〜다）の語幹の最後の母音によって、「아요」と「어요」を使い分けます。「〜します / 〜です」という日常会話で最も使われる丁寧な表現です。

💡 接続公式

💬 語幹の母音による接続ルール

動詞・形容詞の語幹（〜다を取った形）の最後の母音の種類によって形が変わります。

陽性母音（ㅏ, ㅗ） ☀️ 陰性母音（ㅏ, ㅗ 以外） 🌙 하다 で終わる動詞 📝
가다 / 살다 ＋ 아요 먹다 / 마시다 ＋ 어요 공부하(다) ＋ 여요
가요 / 살아요 먹어요 / 마셔요 공부해요
解説
  • 가다（行く / パッチムなし・母音ㅏ）: 語幹の母音が「ㅏ」のため、가 ＋ 아요 ＝ 가요（行きます）になります。
  • 오다（来る / パッチムなし・母音ㅗ）: 語幹の母音が「ㅗ」のため、오 ＋ 아요 ＝ 와요（来ます）になります。（ㅗ＋ㅏ＝와）
  • 기다리다（待つ / パッチムなし・母音ㅣ）: 語幹の母音が「ㅣ」のため、기다리 ＋ 어요 ＝ 기다려요（待ちます）になります。（ㅣ＋ㅓ＝려）
  • 먹다（食べる / パッチムあり・母音ㅓ）: 語幹の母音が「ㅓ」のため、먹 ＋ 어요 ＝ 먹어요［머거요］（食べます）になります。
例文

저는 집에 가요.

私は家に行きます。

친구를 기다려요.

友達を待つ／待ちます。

빵을 먹어요.

パンを食べます。

文法 11-2

動詞の活用変換まとめ

1. 活用ルールのクイック復習

「다」を取った語幹の母音を確認し、3つのパターン（아요 / 어요 / 해요）に分類します。

💡 活用判別フロー

  • ① 語幹の母音が「ㅏ, ㅗ」 ➔ ＋ 아요（가요, 와요, 살아요）
  • ② 語幹の母音が「ㅏ, ㅗ 以外」 ➔ ＋ 어요（먹어요, 기다려요, 마셔요）
  • ③ 「〜하다」で終わる動詞 ➔ 해요 に変化（공부해요, 운동해요）
解説
  • 사다（買う）: 母音「ㅏ」➔ 사요
  • 보다（見る）: 母音「ㅗ」➔ 봐요（ㅗ＋ㅏ＝봐）
  • 마시다（飲む）: 母音「ㅣ」➔ 마셔요（ㅣ＋ㅓ＝려）
  • 읽다（読む）: 母音「ㅣ」➔ 읽어요［イルゴヨ］
  • 공부하다（勉強する）: 하다 ➔ 공부해요
例文

사과를 사요.

りんごを買います。

책을 읽어요.

本を読みます。

한국어를 공부해요.

韓国語を勉強します。

文法 11-3

パッチムあり ＋ 陽性母音「〜아요」

意味・ルール

語幹にパッチムがあり、最後の母音が陽性母音（ㅏ, ㅗ）の場合は、語幹の後ろにそのまま「아요」をつけます。パッチムと「아」が連音化（連音化）して発音されます。

💡 接続公式
語幹の母音：ㅏ ☀️ 語幹の母音：ㅗ ☀️
앉다（座る） ＋ 아요 돕다 / 놀다（遊ぶ） ＋ 아요
앉아요［안자요］ 놀아요［노아요］
解説
  • 앉다（座る）: 語幹「앉」の母音が「ㅏ」のため ➔ 앉 ＋ 아요 ＝ 앉아요［안자요］
  • 살다（住む/生きる）: 語幹「살」の母音が「ㅏ」のため ➔ 살 ＋ 아요 ＝ 살아요［사나요］
  • 놀다（遊ぶ）: 語幹「놀」の母音が「ㅗ」のため ➔ 놀 ＋ 아요 ＝ 놀아요［노아요］
  • 받다（受け取る/貰う）: 語幹「받」の母音が「ㅏ」のため ➔ 받 ＋ 아요 ＝ 받아요［바다요］
例文

주말에 친구와 놀아요.

文法 12

目的語「을/를」＆ 日常の行動

意味

名詞の後ろについて目的語「〜を」を表します。日常の行動（仕事、掃除、勉強など）を表現するときに使われます。

使い分けルール

名詞の最後の文字にパッチム（末尾の子音）があるかないかによって形が変わります。

💡 接続公式

💬 パッチムの有無による接続ルール

名詞の最後の文字にパッチム（末尾の子音）があるかないかによって形が変わります。

パッチム あり ⭕ パッチム なし ❌
일 ＋ 을 청소 ＋ 를
일을 (해요) 청소를 (해요)
解説
  • 일（仕事 / パッチムあり）: 最後の文字に「ㄹ」パッチムがあるため、일 ＋ 을 ＝ 일을 해요（仕事をします）になります。［イレロ］と発音されます。
  • 청소（掃除 / パッチムなし）: 最後の文字「소」にパッチムがないため、청소 ＋ 를 ＝ 청소를 해요（掃除をします）になります。
  • 時間・頻度の表現: 「오늘（今日）」「매일（毎日）」「자주（よく）」「가끔（たまに）」などの単語を文頭に置いて行動を詳しく表現できます。
例文

오늘 일을 해요.

今日、仕事をします。

매일 운동을 해요.

毎日、運動をします。

자주 친구에게 전화를 해요.

よく友達に電話をします。

意味

意味

💡 接続公式

💬 接続ルールと使い分け

文をつなぐ場合と、名詞と名詞をつなぐ場合で形を使い分けます。

形容詞 ＋ -(은)ㄴ ＋ 名詞

意味

形容詞の語幹について、後ろに来る名詞を修飾する「〜な（形容動詞）」「〜い（形容詞）」という連体形（修飾形）を作る表現です。

💬 パッチムの有無による接続ルール

意味

대상 물어보기

뭐 （무엇）

意味

「何」「何を」という意味で、事物や行動の内容をたずねるときに使う疑問代名詞です。（「무엇」の縮約形です）

💡 接続公式

💬 単独で使える！

「무슨」「어떤」のように後ろに名詞をつけず、単独で「뭐예요?（何ですか？）」「뭐 해요?（何をしますか？）」のように使います。

뭐 ＋ 이에요/예요?（何ですか？） 뭐 ＋ 動詞?（何を〜しますか？）

Point

意味
