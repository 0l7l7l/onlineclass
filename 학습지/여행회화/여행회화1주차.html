제 1 과 : 소개하기
[～です / ～じゃないです]
의미

명사 뒤에 붙어 「~입니다」라는 의미를 나타내는 정중형 어미입니다. 단어 뒤에 붙이는 것만으로 상대방에게 예의를 갖춘 완벽한 회화 문장이 됩니다.

💡 접속공식
긍정 · 의문 · 부정 형태별 변화
긍정 / 의문 ⭕
명사 + です
ホテル です
부정 (회화체) ❌
명사 + じゃないです
ホテル じゃないです
Point
  • 의문문 (~입니까?): 문장 끝에 か만 붙여 「～ですか。」로 질문합니다. (예: ホテルですか。)
  • 여행 회화 핵심: 주어나 목적어를 생략해도 단어 뒤에 です만 붙이면 바로 뜻이 통하는 문장이 완성됩니다.
기본 형태 변형 연습
1. [긍정] "학생(学生)입니다."
学生(がくせい) 。
2. [의문] "학생(学生)입니까?"
学生(がくせい) 。
3. [부정] "학생(学生)이 아닙니다."
学生(がくせい) 。
4. [긍정] "역(駅)입니다."
駅(えき) 。
5. [의문] "역(駅)입니까?"
駅(えき) 。
6. [부정] "역(駅)이 아닙니다."
駅(えき) 。
1) です (がくせいです)
2) ですか (がくせいですか)
3) じゃないです (がくせいじゃないです)
4) です (えきです)
5) ですか (えきですか)
6) じゃないです (えきじゃないです)

나라 관련 실전 회화 연습

Q
どこから来ましたか。 도코카라 키마시타카
(어디에서 오셨나요?)
A
韓国からです。 칸코쿠카라 데스
(한국에서 왔습니다 / 한국입니다.)

실전 회화 응용 문제
1. "出身슛신は와どこ도코ですか。데스카"
( "어디 출신이에요?" )
➔韓国칸코쿠 。
( "한국이에요 *한국에서왔어요.")
2. "日本니혼ですか데스카"
( "일본입니까?" )
➔いいえ、이이에日本니혼 。
( "아니요, 일본이 아닙니다.")
3. "中国추고쿠ですか데스카"
( "중국입니까?" )
➔いいえ이이에、 中国추고쿠 。
( "아니요, 중국이 아닙니다." )

4. "出身슛신は 韓国칸코쿠 ですか데스카"
( "한국 출신입니까?" )
➔はい하이、 韓国칸코쿠 。
( "네, 한국 출신입니다." )

5. "どこ도코から카라来키ましたか"
( "어디에서 왔습니까?" )
➔日本니혼から카라 。
( "일본에서 왔습니다." )

1) です (かんこくです)
2) じゃないです (にほんじゃないです)

COLUMN - BREAK TIME

쉬어가기
☕ 읽는 것과 듣는 것의 차이

💴 계산할 때 숫자가 안 들려요!

여행지에서 흔히 겪는 일

일본어를 공부했으니까 여행 가서 일본어로 말해보고 싶다! 그런데 막상 계산할 때가 되면 점원분이 금액을 말하는 순간, 「……え？」 하고 당황하게 되죠. 😳

결국 계산기나 카드 단말기 화면을 바라보거나, 금액을 손으로 가리키면서 계산하는 경우가 많아요. 「これ……？」 하고 가리키는 일은 사실 여행에서 아주 흔한 일입니다.

🛍️
「〇〇円です。」
💭 “방금 뭐라고 했지……?”
🍜
「一、二、〇〇円です。」
💭 “숫자가 하나도 안 들려……!”
읽는 것과 듣는 것의 차이

일본어를 공부한 사람이라도 숫자를 '읽는 것'과 '듣는 것'은 완전히 다르게 느껴질 수 있어요. 특히 계산할 때는 금액을 한 번에 빠르게 말하기 때문에 처음에는 더 어렵게 느껴집니다.

쉬어가기
조금 한적한 곳으로 가보세요

도쿄나 오사카처럼 사람이 많은 관광지에서는 직원이 빠르게 손님을 응대해야 해서 천천히 대화하기 어려울 수 있어요. 그래서 “일본어를 한마디도 못 해봤네?” 하고 아쉬움이 남기도 하죠.

하지만 관광객이 많은 곳에서 조금 벗어나면 손님과 천천히 이야기할 수 있는 작고 한적한 가게들을 만날 수 있습니다.

🙋‍♂️
「これは何ですか？」 / 「いくらですか？」
(이것은 무엇인가요? / 얼마인가요?)
🏪
「これは〇〇ですよ。」 / 「〇〇円です。」
(이것은 〇〇이에요 / 〇〇엔입니다.)
💡 일본어를 ‘말해보고 싶다면’
  • 작은 용기 내보기: 이번 여행에서는 한두 곳쯤 한적한 동네 카페나 가게에서 직접 물건을 사고 물어보세요.
  • 완벽하지 않아도 괜찮아요: “일본어를 공부했으니까 한 번 써보자!” 하는 작은 경험이 다음 일본어 공부를 계속하게 만드는 재미가 됩니다.
이번 여행에서는 이렇게!

화면을 가리키는 대신, 한마디 먼저 말해보세요.
「これはいくらですか？」
그리고 직원의 대답을 이번에는 귀로 한번 들어보세요!
