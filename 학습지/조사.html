CHAPTER 01 · 主題の助詞

은 / 는（〜は）

話題の提示・自己紹介・対比を表す助詞

💡 「은 / 는」のポイント

文のテーマ（〜は）を表す最も基本の助詞です。自己紹介や「これとあれを比べる（対比）」ときに使われます。

🔍 パッチムによる使い分け
パッチム あり (有)
은
학생 + 은 ➔ 학생은
(学生は)
パッチム なし (無)
는
저 + 는 ➔ 저는
(私は)
📌 主なニュアンス・使い所
  • 自己紹介・主題: 「私は〜です」などの話題提示。
    （例：私は韓国人です / 今日は暑いです）
  • 対比（〜は〜だけど）: 2つ以上を比べる時。
    （例：りんごは好きですが、バナナは嫌いです）
01
CHAPTER 01 · 은 / 는 練習
📌 例文で慣れよう
  • 저는 한국 사람이에요.
    私は韓国人です。
  • 이것은 책이에요.
    これは本です。
  • 오늘은 날씨가 좋아요.
    今日は天気が良いです。
Vocabulary · 単語帳
저 私
이것 これ
오늘 今日
사람 人
✏️ 練習問題（은 / 는 を入れましょう）
1. 나 일본 사람이에요. (私「は」日本人です)
2. 선생님 친절해요. (先生「は」親切です)
3. 이름 무엇이에요? (名前「は」何ですか？)
【解答】 1. 는 / 2. 은 / 3. 은

CHAPTER 02 · 主語の助詞

이 / 가（〜が）

動作や状態の主体（主語）を表す助詞

💡 「이 / 가」のポイント

「誰が？何が？」という主語をはっきり指し示します。現象の描写や「〜ではありません（아니에요）」の前にも使われます。

🔍 パッチムによる使い分け
パッチム あり (有)
이
물 + 이 ➔ 물이
(水が)
パッチム なし (無)
가
비 + 가 ➔ 비가
(雨が)
📌 主なニュアンス・使い所
  • 新情報・描写: 目に見えた現象をそのまま伝える時。
    （例：あ！雨が降ってきた！ / 電車が来ます）
  • 指定・疑問詞を受ける: 「誰が・何が」の回答。
    （例：誰が来ましたか？ ➔ 田中さんが来ました）
03
CHAPTER 02 · 이 / 가 練習
📌 例文で慣れよう
  • 비가 와요.
    雨が降ります。
  • 시간이 있어요?
    時間がありますか？
  • 내가가（※내+가） 할게요.
    私がやります。（※내가, 제 가 など変化に注意）
Vocabulary · 単語帳
비 雨
시간 時間
돈 お金
친구 友達
✏️ 練習問題（이 / 가 を入れましょう）
1. 돈 없어요. (お金「が」ありません)
2. 친구 왔어요. (友達「が」来ました)
3. 버스 출발해요. (バス「が」出発します)
【解答】 1. 이 / 2. 가 / 3. 가
04
CHAPTER 03 · 目的語の助詞

을 / 를（〜を）

動作の対象（〜を）を表す助詞

💡 「을 / 를」のポイント

「何を食べる？何を観る？」など、動詞の目的語（動作がかかる対象）につける助詞です。

🔍 パッチムによる使い分け
パッチム あり (有)
을
밥 + 을 ➔ 밥을
(ご飯を)
パッチム なし (無)
를
영화 + 를 ➔ 영화를
(映画を)
📌 日本語との違いに注意！
  • 「〜に会う」は韓国語で「〜を会う」:
    日本語では「友達に会う」ですが、韓国語では 친구를 만나다（友達を会う）と言います。
  • 「〜が好き・嫌い」も「〜を」を使うことがある:
    좋아하다（好む）を使う時は BTS를 좋아해요（BTSを好きです）になります。
05
CHAPTER 03 · 을 / 를 練習
📌 例文で慣れよう
  • 밥을 먹어요.
    ご飯を食べます。
  • 커피를 마셔요.
    コーヒーを飲みます。
  • 한국어를 공부해요.
    韓国語を勉強します。
Vocabulary · 単語帳
밥 ご飯
커피 コーヒー
책 本
음악 音楽
✏️ 練習問題（을 / 를 を入れましょう）
1. 책 읽어요. (本「を」読みます)
2. 음악 들어요. (音楽「を」聴きます)
3. 사과 사요. (リンゴ「を」買います)
【解答】 1. 을 / 2. 을 / 3. 를

CHAPTER 04 · 総合まとめ

助詞の使い分け比較

「은/는」「이/가」「을/를」を総復習！

💡 「은/는」vs「이/가」の違いの整理

은/는（〜は）：相手に「〜について話すよ」と主題を提示する。
이/가（〜が）：「誰が？何が？」という主語を特定・強調する。

🔍 一覧で比べるパッチム法則
助詞の役割 パッチムあり (有) パッチムなし (無)
〜は (主題) 은 는
〜が (主語) 이 가
〜を (目的語) 을 를
📌 ニュアンス比較の例文

• 이것은 책이에요.（これは本です ➔ 「これ」について説明）
• 이것이 책이에요.（これが本です ➔ 「これが！」と指定）

07
CHAPTER 04 · 総まとめテスト
✏️ 総合クリアテスト

文脈に合わせて正しい助詞を選んで書き入れましょう。

1. 저 Tanaka예요. (私「は」田中です)
2. 비 와요. (雨「が」降ります)
3. 밥 먹었어요. (ご飯「を」食べました)
4. 친구 만나요. (友達「に/を」会います)
5. 학생 아니에요. (学生「では」ありません ※이/가を使う)
6. 영화 봐요. (映画「を」見ます)
【解答・解説】
1. 는（自己紹介の「は」） / 2. 가（現象の描写「が」）
3. 을（目的語「を」） / 4. 를（韓国語では「友達を会う」）
5. 이（〜ではない「아니에요」の前は이/가） / 6. 를（目的語「を」）
