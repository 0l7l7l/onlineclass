韓国語基礎 (Hangul Structure)

ハングル文字の仕組み

子音(子音)・母音(母音)・パッチム(終音)の位置をマスターしましょう！

02 / 06

1. 日本語との比較 (語順と構造)

① 語順(SOV)は全く同じ！

・日本語：私は 学生です。

・韓国語：わたしは(わたしは) がくせい(がくせい) です(です)。

② 日本語の「かな」との文字構造の違い

・「か (K+A)」のように、ハングルも【子音 + 母音】を組み合わせて1つの文字を作ります。

03 / 06

2. 子音と母音の位置関係

母音の形によって、並べる位置が変わります！

① 縦長母音 (ㅏ, ㅓ, ㅣなど) → 左右配置

子音 (ㄱ)
母音 (ㅏ)

ㄱ + ㅏ = 가 (ga)

② 横長母音 (ㅗ, ㅜ, ㅡなど) → 上下配置

子音 (ㄱ)
母音 (ㅗ)

ㄱ + ㅗ = 고 (go)

04 / 06

3. パッチム(パッチム)の位置

文字の「一番下(底)」に入る最後の子音を「パッチム」と呼びます。

初声 (ㄱ)
中声 (ㅏ)
パッチム (ㅇ)

ㄱ + ㅏ + ㅇ = 강 (gang)

※ 日本語の「ん(n/m/ng)」や「っ(t/k/p)」のような役割をします。

05 / 06

4. 確認クイズ (Quiz)

次の組み立てで完成するハングルは何でしょうか？

[ 子音: ㄱ ] + [ 母音: ㅗ ] + [ パッチム: ㅁ ] = ?

곰 (gom = クマ)

06 / 06

5. 本日のまとめ

  • ✅ 子音 + 縦長母音 ＝ 左右に並べる (例: 가, 나)
  • ✅ 子音 + 横長母音 ＝ 上下に並べる (例: 고, 노)
  • ✅ パッチム ＝ 必ず文字の一番下に配置する (例: 강, 곰)

韩语基础 (Hangul Structure)

韩文构造与拼写位置

轻松掌握辅音(声母)、元音(韵母)与收音(韵尾)的位置！

02 / 06

1. 与中文的对比 (语序与拼音)

① 语序的不同 (主语 + 宾语 + 谓语)

・中文 (SVO)：我是 学生。

・韩语 (SOV)：我是(我是) 学生(学生) 是(是)。

② 拼写构造与汉语拼音相似！

・韩文如同拼音，由 【辅音(声母) + 元音(韵母)】 组合成一个方块字。

03 / 06

2. 辅音与元音的位置关系

根据元音的形状，排列位置有所不同：

① 竖直元音 (ㅏ, ㅓ, ㅣ) → 左右结构

辅音 (ㄱ)
元音 (ㅏ)

ㄱ + ㅏ = 가 (ga)

② 横向元音 (ㅗ, ㅜ, ㅡ) → 上下结构

辅音 (ㄱ)
元音 (ㅗ)

ㄱ + ㅗ = 고 (go)

04 / 06

3. 收音(Batchim)的位置

位于韩文字「最底部」的最终辅音被称为“收音”。

声母 (ㄱ)
韵母 (ㅏ)
收音 (ㅇ)

ㄱ + ㅏ + ㅇ = 강 (gang)

※ 类似于汉语拼音中的前鼻音(-n)和后鼻音(-ng)等韵尾。

05 / 06

4. 随堂测试 (Quiz)

请拼读以下组合拼出的韩文字：

[ 辅音: ㄱ ] + [ 元音: ㅗ ] + [ 收音: ㅁ ] = ?

곰 (gom = 熊)

06 / 06

5. 本课小结

  • ✅ 辅音 + 竖直元音 ＝ 左右排列 (例: 가, 나)
  • ✅ 辅音 + 横向元音 ＝ 上下排列 (例: 고, 노)
  • ✅ 收音 (Batchim) ＝ 永远放在文字的最下方 (例: 강, 곰)
