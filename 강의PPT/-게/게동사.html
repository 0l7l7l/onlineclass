한국어 문법 (日本語で説明)
形容詞 + -게 + 動詞
「どんな状態で / どんなやり方で～するか」を表します。
1
1. 基本意味
形容詞の後ろに -게 をつけると、「～に / ～く」 の意味になります。
つまり、形容詞 → 副詞 に変わります。

빠르다 → 빠르게
조용하다 → 조용하게
예쁘다 → 예쁘게
쉽다 → 쉽게
後ろには動詞が来ます: 빠르게 달리다 / 조용하게 말하다
2
2. いつ使う？
動作の「やり方」を説明するとき
그 사람은 빠르게 걸어요.
彼は速く歩きます。
선생님이 쉽게 설명해요.
先生が分かりやすく説明します。
아이가 조용하게 말하고있어요.
子どもが(小さい声)静かに話しています。
3
3. 作り方
① 一般形容詞
크다 → 크게
작다 → 작게
쉽다 → 쉽게
어렵다 → 어렵게
좋다 → 좋게
② -하다 形容詞
조용하다 → 조용하게
친절하다 → 친절하게
정확하다 → 정확하게
4
4. よく使う表現
形容詞-게 形例文
빠르다빠르게빠르게 걸어요.
쉽다쉽게쉽게 설명해 주세요.
차갑다차갑게차갑게 주세요.
조용하다조용하게조용하게 말해 주세요.
친절하다친절하게친절하게 안내 해 줬어요.
5
5. -게 のニュアンス
예쁘다 → 예쁜 상태
「きれいな状態」
예쁘게 입다
きれいな姿で着る
조용하다 → 조용한 상태
「静かな状態」
조용하게 이야기하다
静かなやり方で話す
形容詞は「状態」、-게 がつくと「その状態で行動する」意味になります。
6
まとめ
形容詞 + 게 + 動詞
01
「どうやって～するか」を表す。
02
形容詞が副詞に変わる: 빠르다 → 빠르게
03
例: 쉽게 설명하다 / 조용하게 말하다
