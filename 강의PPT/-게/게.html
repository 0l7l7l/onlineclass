오늘의 문법

형용사 + -게

형용사를 이용해서 "어떻게 하는지" 표현해요.

깨끗하다 → 깨끗하게 | 조용하다 → 조용하게 | 쉽게 → 쉽게

4P. -게는 무슨 뜻일까요?

❓ どうやって掃除しますか? 👉 → きれいに掃除しています。 　

❓ どうやって話しますか? 👉 → 静かに話しています。　

❓ どうやって説明しますか? 👉 簡単に説明しています。

-게 = どうやって (어떻게?)
5P. 어떻게 변형해요?
형용사: 깨끗하다 → 깨끗하게

• 예쁘다 → 예쁘게

• 조용하다 → 조용하게

• 쉽다 → 쉽게

• 맛있다 → 맛있게

7P. ⚠️ 잠깐! -게가 아닌 경우도 있어요

한국어의 부사는 전부 -게가 아니에요.

단어부사예문

11P. 회화 연습

A: どうやって話すべきでしょうか?

B: 静かに話してください。/조용하게 말해 주세요.

12P. 직접 만들어 보기

💬 알맞은 형용사를 골라 완성해 보세요!

③ どうやって勉強しますか? → 一生懸命勉強しています。열심히 공부해요.
