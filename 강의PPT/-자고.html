01. 오늘의 문법

-자고 하다

「～しよう」と言う / 伝える

오늘은 다른 사람이 한 말을 전달해 봅시다!

친구가 "같이 가자!"라고 했어요.

⬇️

친구가 같이 가자고 했어요.

02. 상황 제시

👩‍🏫 선생님

"주말에 뭐 할까요?"

👩 친구

"영화 보자!"

❓ 질문: 친구가 뭐라고 했어요?

03. '-자' 복습

친근한 사이에서 제안할 때 사용하는 표현을 복습해 봅시다!

기본형 -자 (제안) 日本語
가다가자!行こう！
먹다먹자!食べよう！
보다보자!見よう！
공부하다공부하자!勉強しよう！

"가자!"는 일본어로 ➔ 「行こう！」

04. '-자고' 등장

🗣️ 직접 말하면 (Direct Speech)

👩 "같이 가자!"

⬇️ 다른 사람에게 전달하면? (Indirect)

👩 친구가 같이 가자고 했어요.

가자 + 고 ➔ 가자고

여기서 '고'의 역할은 일본어의 「～と」 입니다. (가자고 ➔ 「行こう」と)

05. 핵심 비교 (Core Comparison)

🗣️ 직접 말하기

가자!

「行こう！」

내가 직접 제안

➡️

💬 말 전달하기

가자고 했어요.

「行こう」と言いました。

다른 사람의 제안을 전달

06. 문법 공식

⭐ 동사 + 자고 하다

기본형 동사 + 자고 하다
가다가자고 하다
먹다먹자고 하다
보다보자고 하다
공부하다공부하자고 하다

의미: 「～しよう」と言う / 「～しよう」って言う

07. 변형 연습 ①

다음을 바꿔 보세요! ( '-자!' ➔ '-자고 했어요.' )

1. 가다 ➔ 가자! ➔ 가자고 했어요.

2. 먹다 ➔ 먹자! ➔ 먹자고 했어요.

3. 보다 ➔ 보자! ➔ 보자고 했어요.

4. 공부하다 ➔ 공부하자! ➔ 공부하자고 했어요.

08. 변형 연습 ②

기본형에서 바로 '-자고 하다'로 변형해 보세요!

먹다 ➔ 먹자고 하다

마시다 ➔ 마시자고 하다

자다 ➔ 자자고 하다

만나다 ➔ 만나자고 하다

공부하다 ➔ 공부하자고 하다

놀다 ➔ 놀자고 하다

09. 문장 변형 연습

문장 전체를 전달 표현으로 바꿔 봅시다!

친구: "같이 밥 먹자." ➔ 친구가 같이 밥 먹자고 했어요.

1. 친구: "카페에 가자."

➔ 친구가 카페에 가자고 했어요.

2. 친구: "영화를 보자."

➔ 친구가 영화를 보자고 했어요.

3. 친구: "한국어를 공부하자."

➔ 친구가 한국어를 공부하자고 했어요.

10. 했어요 vs 했잖아요

🔵 가자고 했어요.

친구가 가자고 했어요.

친구가 「行こう」と言いました。

👉 단순한 사실 전달

🔴 가자고 했잖아요!

친구가 가자고 했잖아요.

友達が「行こう」って言ったじゃないですか。

👉 이미 알고 있는 사실을 상기/확인

11. 상황 연습

상황 ① (사실 전달)

선생님: 어제 친구하고 약속했어요. 친구가 "토요일에 만나자!"라고 했어요. 뭐라고 할까요?

➔ "친구가 토요일에 만나자고 했어요."

상황 ② (기억 상기)

선생님: 그런데 친구가 오늘 약속을 잊어버렸어요! 뭐라고 말할까요?

➔ "같이 만나자고 했잖아요!"

12. 선택 문제

친구가 말했어요: "내일 같이 공부하자!"

어떻게 말할까요?

13. 일본어 ➔ 한국어

다음 일본어를 한국어로 바꿔 보세요!

1. 「一緒に行こう」と言いました。

➔ 같이 가자고 했어요.

2. 「ご飯を食べよう」って言いました。

➔ 밥을 먹자고 했어요.

3. 「映画を見よう」と言いました。

➔ 영화를 보자고 했어요.

14. 듣고 말하기

선생님의 말을 듣고 제안 전달 문장으로 바꿔 보세요! ⭐

👩‍🏫 선생님: "주말에 같이 카페 가자!"

학생 ➔ 카페에 가자고 했어요.

👩‍🏫 선생님: "내일 같이 밥 먹자!"

학생 ➔ 밥 먹자고 했어요.

👩‍🏫 선생님: "한국어 공부하자!"

학생 ➔ 한국어 공부하자고 했어요.

15. 문장 만들기

주어와 내용을 직접 골라 문장을 만들어 봅시다!

1단계: 친구에게 제안하기

"같이 여행 가자!"

2단계: 선생님의 질문에 답하기 ("친구에게 뭐라고 했어요?")

➔ "친구에게 여행 가자고 했어요."

16. 🎭 역할극 (Role Play)

1:1 대화 상황입니다. 제안 카드에서 하나를 골라 대화해 보세요!

🎬 카테고리: 영화 보기 / 밥 먹기 / 카페 가기 / 쇼핑하기 / 공부하기

A: "우리 [ 영화 보기 ] 하자!"

B: "친구가 뭐라고 했어요?"

A: "친구가 [ 영화 보자고 ] 했어요."

17. 실전 응용 (Real Practice)

실제 대화에서 '-자고 했잖아요!'를 사용하는 상황들입니다.

😮 상황 1: 친구가 약속을 잊어버렸을 때

친구: "오늘 뭐 하지?" ➔ 학생: "같이 영화 보자고 했잖아요!"

😮 상황 2: 친구가 다른 식당에 가려고 할 때

학생: "저 식당에 가자고 했잖아요!"

😮 상황 3: 친구가 혼자 공부하려고 할 때

학생: "같이 공부하자고 했잖아요!"

18. 오늘 배운 것 (Summary)

🌱 오늘 배운 핵심 정리
