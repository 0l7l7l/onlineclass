平假名是怎样形成的？

在开始记忆之前，先来了解平假名独特的奥秘吧！

02

1. 글자 탄생의 차이: [조립형 vs 완성형]

한글은 레고처럼 조립하지만, 히라가나는 소리가 레디메이드(완성형)입니다!

🇰🇷 한글 (조립형)

자음과 모음이 합쳐짐

ㄱ + ㅏ = 가

[자음 따로, 모음 따로!]

🇯🇵 히라가나 (완성형)

글자 하나에 소리가 통째로!

か (ka)

[K + A 소리가 한 글자에 완비!]

02

1. 造字方式的差异：[拼音拼读 vs 整体发音]

平假名每个字母自带固定的【辅音+元音】发音！

🇨🇳 汉语拼音 (拼读)

声母 + 韵母 拼合

k + a = ka

[声母与韵母分开组合]

🇯🇵 日文平假名 (整体)

单字直接代表完整音节

か (ka)

[自带 k+a 完整音节！]

03

2. 히라가나의 비밀지도: [5음도 아파트]

히라가나는 체계적인 '아파트 동/호수' 규칙으로 정리되어 있습니다!

🏢 층수 (단): あ·い·う·え·お (5개의 기본 모음 = 5개 층)

🚪 동 이름 (행): あ행, か행, さ행, た행... (자음 계열 = 동 건물)

👉 예: か (ka)는 'か동(K)의 1층(あ)'에 사는 글자입니다!

03

2. 平假名的秘密地图：[五十音图公寓]

平假名有着像“公寓楼层与门牌”一样非常系统化的规则！

🏢 楼层 (段): あ·い·う·え·お (5个基本元音 = 5个楼层)

🚪 楼栋 (行): あ行, か行, さ行, た行... (辅音系列 = 不同楼栋)

👉 例如：か (ka) 就是住在 “か栋(K) 1层(a)” 的字母！

04

3. 한자를 흘려 쓰다가 탄생한 글자!

옛날 일본 사람들이 한자를 예쁘게 흘려 쓰다가 귀여운 히라가나가 되었답니다.

安 (편안할 안) ➡ 流 (흘려쓰기) ➡ あ

* 동글동글 부드러운 선으로 이어 쓰면 바로 히라가나 완성!

🚀 그럼 가장 기본이 되는 [あ행] 아파트부터 들어가 볼까요?

04

3. 由汉字草书演变而来的草体字母！

古代日本人将繁复的汉字草写，演变成了如今可爱的平假名。

安 (平安之安) ➡ 草书演变 ➡ あ

* 笔画圆润连贯，就变成了平假名！

01

일본어 발음 규칙 (Rules)

탁음과 반탁음

글자 오른쪽 위에 점(゛)이나 동그라미(゜)를 붙이는 규칙입니다.

01

日文发音规则 (Rules)

浊音与半浊音

在假名右上角添加两点(゛)或小圆圈(゜)的发音变音规则。

02

1. 탁음 (濁音)

글자 우측 상단에 점 두 개 (゛)를 붙여 울리는 소리를 만듭니다.

・ か (카) ＋ ゛ → が (가)

・ さ (사) ＋ ゛ → ざ (자)

・ た (타) ＋ ゛ → だ (다)

・ は (하) ＋ ゛ → ば (바)

02

1. 浊音 (濁音)

在假名右上角加上两点 (゛)，使其发音变为浊音：

・ か (ka) ＋ ゛ → が (ga)

・ さ (sa) ＋ ゛ → ざ (za)

・ た (ta) ＋ ゛ → だ (da)

・ は (ha) ＋ ゛ → ば (ba)

03

2. 반탁음 (半濁音)

は행 (は, ひ, ふ, へ, ほ) 우측 상단에 작은 동그라미 (゜)를 붙여 'P' 발음으로 바꿉니다.

・ は (하) ＋ ゜ → ぱ (파)

・ ひ (히) ＋ ゜ → ぴ (피)

・ ふ (후) ＋ ゜ → ぷ (푸)

03

2. 半浊音 (半濁音)

仅在 は行 右上角加上小圆圈 (゜)，发成 "P" 音：

・ は (ha) ＋ ゜ → ぱ (pa)

・ ひ (hi) ＋ ゜ → ぴ (pi)

・ ふ (fu) ＋ ゜ → ぷ (pu)

04

규칙 정리

  • ✅ ゛ (탁음) : 가, 자, 다, 바 행 발음으로 변경
  • ✅ ゜ (반탁음) : は행에만 부착 가능 (파, 피, 푸, 페, 포)
04

规则小结

  • ✅ ゛ (浊音) : 变为 g, z, d, b 开头的浊音
  • ✅ ゜ (半浊音) : 仅用于 は 行，变为 p 开头的发音
